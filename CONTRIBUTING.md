# Contributing to DOOM

Start with the [contribution guide](docs/community/CONTRIBUTION_GUIDE.md), [SDK quick start](docs/developers/QUICKSTART.md), or [mod developer quick start](docs/community/DEVELOPER_QUICKSTART.md). File ordinary reproducible SDK or host defects with the issue template. Use private feedback for tester diagnostics and the [security process](SECURITY.md) for suspected vulnerabilities. Include a regression test and exact commands for each fix.
