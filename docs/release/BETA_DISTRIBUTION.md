# Beta Distribution

Distribution is blocked pending security and performance approval. Private APK delivery needs an access-controlled channel, the approved direct signing certificate, SHA-256 and explicit tester opt-in. A GitHub prerelease draft supports maintainer review. Publishing it can expose the artifact to everyone with repository access. Google Play internal and closed tracks require an authorized Play account, an upload-signed AAB and configured tester access. Internal testing supports a small invited group. Closed testing uses managed cohorts and applicable Play review and testing requirements. Check the account-specific requirements before enrollment. See https://support.google.com/googleplay/android-developer/answer/9845334. Stop distribution on incidents and issue a higher-code corrective update.
