# Release Notes

DOOM 0.1.0-beta.1 (code 2) was the installed internal beta preceding this candidate. Settings displays the installed app version. Benchmark installations use a separate application ID. Release builds support an external signing identity and isolate the debug marketplace endpoint. Remote marketplace use, release signing verification, security device scenarios and release-like performance measurements remain open. No external rollout has been approved.

## Candidate version

DOOM 0.1.0-beta.2 (code 3) is the Milestone 13C.2 internal candidate version. It is unsigned until the approved channel signing identity and production HTTPS endpoint are configured. It has not been distributed.
