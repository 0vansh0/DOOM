# Community Support Operations

Use `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `docs/community/CONTRIBUTION_GUIDE.md`, `docs/developers/QUICKSTART.md`, SDK reference, and compatibility policy. The current SDK contract is declarative: Manifest Schema 3, SDK API 2, Definition V3 and V4, with capabilities enforced by the host. No arbitrary executable mod code or general shell/network access is supported.

Ordinary reproducible defects go through the repository issue workflow; private tester diagnostics stay in authorized private feedback and expire under the backend's 30-day policy. Do not include credentials, raw logs, private feedback contents, or personal files in public reports. Vulnerabilities follow `SECURITY.md`; no public security contact address was supplied. No staffed public support email/service or public beta intake is configured, so these must be established and reviewed before inviting outside testers.

Community examples are source fixtures, not public marketplace releases. Test their manifest/definition with the CLI and importer tests; do not claim device execution solely from desktop simulation.
