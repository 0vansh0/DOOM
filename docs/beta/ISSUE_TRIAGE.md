# Reviewing feedback

Open Issue triage with a reviewer or administrator account. Filter by status, inspect the affected app and Android versions, and record a component, priority, reproduction status and regression test reference. Save the outcome under the original report UUID. Status progresses from open to in-progress to resolved. Reopen a report when its fix fails retesting. See [priority definitions](FEEDBACK_TRIAGE.md). For longer-lived engineering work, record a sanitized issue separately before private feedback expires. Never copy private attachments into a public tracker.
