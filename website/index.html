Sandboxed by schema,
not promises.

Community packages contain declarative data, not executable mod code. DOOM validates definitions against supported schemas, capabilities and trusted native actions before runtime.

No mod code loader

Packages describe events, conditions, settings and allowlisted actions. They do not provide Java, Kotlin or shell execution.

Review before enable

Inspect declared capabilities and required Android access before enabling a mod. A declaration never grants permission by itself.

Safe Mode

Use DOOM’s Safe Mode to suspend third-party mod execution. Recovery tools remain available for unresolved changes.

Create. Validate.
Package.

Use the checked-in CLI to scaffold a sample, validate its schema, run a scenario and build a .doommod archive. Device installation uses DOOM’s importer and separate user approval.
