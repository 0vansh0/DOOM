SUPPORT

Help us understand what happened.

The app’s Help & Feedback screen can export a report locally. Server submission requires an authenticated account, explicit consent, and a configured trusted service. The current release endpoint is not publicly available.

Preparing a useful report

  1. Include the app version and Android API level.
  2. Name the mod only if relevant; do not include account passwords, tokens, private files or full device identifiers.
  3. List reproduction steps, expected behavior and what actually happened.
  4. Share a diagnostic export or screenshot only after reviewing it for private data.

Safety and recovery

Disable an affected mod first. Use Safe Mode to suspend third-party mod execution. If DOOM records a system change requiring recovery, use the Recovery Center and follow its current authorization checks. Shizuku is optional; never grant it to troubleshoot ordinary mods.

Current support channel

No public support address or staffed service has been configured. For local testing, export a report and share it through a private channel selected by the project owner. Do not submit sensitive information to public issue trackers. A public beta must not open until an approved support contact and report-handling process are published.
